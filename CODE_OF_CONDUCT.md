# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

## Our pledge

We pledge to make participation in our community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, colour, religion, or sexual identity and orientation.

In short: be respectful, assume good intent, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, insults, trolling, and publishing others' private information are not acceptable.

## Scope

This code applies in all project spaces (issues, pull requests, discussions) and when someone officially represents the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the project maintainers through the contact details on the repository's GitHub profile page, or by using GitHub's [*Report content*](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature. Maintainers will review every report promptly and fairly, and will respect the reporter's privacy.

## Enforcement

Maintainers may take any action they consider appropriate, from a warning to a permanent ban, following the [Contributor Covenant enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
